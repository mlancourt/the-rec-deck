| Press Start 2P (pixel display font) | `public/fonts/PressStart2P-Regular.ttf` | SIL Open Font License 1.1 — full text in `public/fonts/OFL-PressStart2P.txt` | Copyright 2012 The Press Start 2P Project Authors (cody@zone38.net). Reserved Font Name "Press Start 2P". Vendored unmodified from github.com/google/fonts (`ofl/pressstart2p`). |

The font is used only for the marquee wordmark, cartridge titles, and scoreboard digits. Everything else uses the system font stack. No fonts are fetched at runtime from any third party.

Icons in `public/icons/` are generated by `tools/gen-icons.ts` (original work, same license as this repo). Sound cues are synthesized at runtime with WebAudio; there are no audio files.
